# Погоня и Кубомир

Два 3D-проекта на Three.js и TypeScript.

## Погоня

Ночная анимация: ты едешь по пустой трассе, а сзади бежит убийца в маске и с ножом.

Открыть: https://thisisfortiktok259-ux.github.io/-/

- C или клик: сменить камеру (из машины с зеркалом, спереди, из-за спины убийцы, сбоку)
- M: включить или выключить звук

## Кубомир

Песочница из блоков в духе Minecraft: https://thisisfortiktok259-ux.github.io/-/game.html

W, A, S, D: ходьба. Пробел: прыжок. Дважды W: бег. Дважды пробел: полёт, Shift: вниз. Левая кнопка мыши: сломать, правая: поставить. 1–9 или колесо: выбор блока. F3: отладка. Esc: пауза.

## Локальный запуск

```
npm install
npm run dev
```
