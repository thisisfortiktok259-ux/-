# Кубомир

Браузерная 3D-песочница из блоков в духе Minecraft на Three.js и TypeScript.

## Играть

Онлайн: https://thisisfortiktok259-ux.github.io/-/

Нужен компьютер с клавиатурой и мышью и последняя версия Chrome, Edge или Firefox.

## Управление

| Действие | Клавиша |
|---|---|
| Ходьба | W, A, S, D |
| Прыжок | Пробел |
| Бег | Дважды W |
| Полёт (вкл/выкл) | Дважды пробел |
| Вверх / вниз в полёте | Пробел / Shift |
| Сломать блок | Левая кнопка мыши |
| Поставить блок | Правая кнопка мыши |
| Выбор блока | 1–9 или колесо мыши |
| Отладочный экран | F3 |
| Пауза | Esc |

## Локальный запуск

```
npm install
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173).

## Сборка и тесты

```
npm run build
npm test
```

Название Minecraft принадлежит Mojang и Microsoft. Кубомир не связан с ними и использует собственные текстуры, которые рисует код.
